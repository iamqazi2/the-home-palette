# Writing for the Journal

Journal posts are real Shopify blog posts. They are written in **Shopify admin → Content → Blog
posts**, not in the theme customizer.

## One-time setup

1. Admin → **Content → Blog posts → Manage blogs → Add blog**.
2. Title it **Journal**. Its URL must end in `/blogs/journal` — `/pages/journals` is already set to
   read that blog, and switches over by itself the moment the blog has a post.
3. Re-create the existing stories there, one post each (the old theme blocks keep showing until the
   blog has its first post, so the page is never empty in between).

## Writing a post

Admin → Content → Blog posts → **Add blog post**, then choose the **Journal** blog.

| You want | Where |
|---|---|
| Headings H2–H6 | Editor toolbar, first dropdown ("Paragraph" → Heading 2 … Heading 6). Use H2 for main sections, H3 below it. The post title is already the page's H1. |
| Bold, italic, lists, quotes, tables | Editor toolbar |
| A link / backlink | Select text → link icon. Link to products and collections on this store, or to other sites. |
| Image inside the post | Editor toolbar → image icon → upload. Fill in the alt text. |
| Video | Editor toolbar → video icon, paste a YouTube or Vimeo link. It fills the width on every screen. |
| Hero image | **Image** panel on the right |
| Card summary | **Excerpt** (if blank, the first lines of the post are used) |
| Filter chip on the Journal | **Tags** — the **first** tag is the post's topic chip |
| Meta title, meta description, URL | **Search engine listing** at the bottom → Edit. The URL handle becomes `/blogs/journal/<handle>`. |
| Publish later | **Visibility** → set a date |

The theme adds the date, reading time, tags, previous/next links and BlogPosting structured data
automatically. Title, description, canonical URL and social-share tags come from the Search engine
listing fields.
