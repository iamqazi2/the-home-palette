Recording Script

A 90-second screen recording proving that one tag puts a product into a colour on the storefront. Exact clicks, exact words, exact product.

Rehearse before you record. No product in the store has ever carried a colour tag, so this specific path has never run on the live site. Section 1 is a five-minute rehearsal that removes all risk. Do not skip it.

Version 1.0 · 7 September 2026 · Store: thehomepalette.com.pk
Subject: Arabic Mandi Platter → copper · Copper swatch verified at 4 products today

What you are recording

The Arabic Mandi Platter is copper-toned metalware, but the word "copper" is nowhere in its name — so today it appears under no colour swatch at all. You add one tag, refresh, and it joins the Copper palette. That is the whole video.

Why this productNo colour in its name, and its only variant option is size (12 inch / 14 inch) — so the colour tag is what decides where it goes
The one thing that would ruin the take. If a product sells in several colours from one listing — a variant option named Color, Colour, Shade or Glaze — the theme uses that option and ignores colour tags completely. Persian Metal Handi is exactly this: it has a Color option with values Copper and Silver, which is why it already shows under both swatches without any tag. Record with the Arabic Mandi Platter, which has no such option.

1. Rehearsal — do this first, off camera

Five minutes. It proves the tag path works and leaves the store exactly as it was.

  1. Open the homepage → Shop by Colour → click Copper. Count the products. You should see 4.
  2. Shopify admin → Products → Arabic Mandi Platter → Product organization → Tags.
  3. Type copper, press Enter, click Save.
  4. Back to the homepage. Hard-refresh: Cmd+Shift+R. Click Copper again.
  5. Did the Arabic Mandi Platter appear, making 5? If yes, you are clear to record — go to step 6. If no, read the box below before doing anything else.
  6. Remove the copper tag again (click the × on the chip → Save) so the "before" state is clean for the take. Hard-refresh and confirm you are back to 4.
If the platter did not appear in the rehearsal. Do not record this demo. The live theme is a newer build than the one in our repository, and while colour matching by product name and by variant option are both confirmed working on the live site today, matching by tag has never actually run there — no product in the catalogue has ever had a colour tag. Tell me and I will check the published theme. In the meantime record the Shop by Occasion demo instead: that path is proven, it is already in daily use, and the runbook for it is written.

2. Set up the screen

  • Two tabs only: Tab 1 Shopify admin (Products list), Tab 2 the live homepage
  • Close every other tab — bookmarks bar, other stores and personal tabs will be in the frame
  • Sign out of, or hide, anything showing a personal email address in the admin header
  • Browser zoom at 100%, window maximised, notifications set to Do Not Disturb
  • Record the browser window only, not the whole desktop
  • Confirm the Copper swatch is showing 4 products before you press record
Always hard-refresh — Cmd+Shift+R (Mac) or Ctrl+F5 (Windows). A normal refresh can serve a cached page and make a working demo look broken on camera.

3. The take — roughly 90 seconds

Shot 1 — the problem

0:00 – 0:20 · Tab 2, homepage
  1. Start on the homepage, already scrolled to Shop by Colour.
  2. Click the Copper swatch. Let the four products load and settle.
  3. Move the cursor slowly across the four cards as you speak — do not click them.

"This is Shop by Colour. Here's Copper — four pieces. What's missing is our Arabic Mandi Platter, which is copper metalware. It isn't here, because the word 'copper' isn't in its name, so the site has no way of knowing what colour it is."

Shot 2 — add the tag

0:20 – 0:55 · Tab 1, admin
  1. Switch to the admin tab. Search Arabic Mandi in the Products list and open the product.
  2. Scroll the right-hand column to Product organization. Pause a beat so it is clearly visible.
  3. Click into the Tags field. Type copper slowly — this is the moment the video exists for.
  4. Press Enter. Let the grey chip appear on screen for a full second.
  5. Click Save and wait for the confirmation toast.

"So I go to the product, into Product organization, and I add one tag: copper. That's it. I'm not touching the website, I'm not touching any code — I'm describing the product."

Type it, do not paste. The client needs to see how little work this is. If Shopify offers copper in the autocomplete dropdown, still let the viewer see the word being typed before you select it.

Shot 3 — the payoff

0:55 – 1:20 · Tab 2, homepage
  1. Switch back to the homepage tab.
  2. Hard-refresh: Cmd+Shift+R.
  3. Scroll back to Shop by Colour and click Copper again.
  4. Five products now. Move the cursor onto the Arabic Mandi Platter card and let it rest there.

"Refresh — and there it is. Five pieces now, and the Mandi platter is in the copper palette. That took one word and about ten seconds, and anyone on the team can do it."

Shot 4 — reversible (optional, strong finish)

1:20 – 1:40

This beat doubles as your cleanup, so it costs nothing to include.

  1. Back to the admin tab, same product, click the × on the copper chip, click Save.
  2. Homepage → hard-refresh → Copper. Back to four.

"And it's just as easy to undo. Remove the tag, and it leaves the palette. Nothing is permanent, nothing can break — it's only ever a label on a product."

4. If it does not appear mid-take

Stop the recording rather than troubleshooting on camera. Then work down this list.

CheckWhat to do
Did you hard-refresh?Cmd+Shift+R. This is the cause nine times out of ten.
Is the tag actually saved?Reopen the product. You should see a grey copper chip. If you typed it but never pressed Enter, it was not saved.
Is it spelled exactly copper?All lowercase, no trailing space. A capital C creates a different tag.
Right product?It must be Arabic Mandi Platter (arabic-mandi-platter), not Persian Metal Handi or Mughal Serving Platter.
Still nothing?The tag branch of the live theme needs checking. Send me a note and record the Shop by Occasion demo instead — that one is proven and already in daily use.

5. After you stop recording

  • Remove the copper tag from the Arabic Mandi Platter — unless shot 4 already did it, or you want to keep it (it is a genuinely correct tag for that product)
  • Hard-refresh and confirm the Copper swatch reads whichever number you intended to leave it at
  • Watch the recording back before sending — check no personal email, order data or customer name is visible in any frame
Two notes for when the client asks follow-up questions
  • Colour tags need no setup. Unlike Occasion and Style, Shop by Colour uses no collections — the theme reads the tag straight off the product. That is why this demo works instantly with nothing prepared.
  • Multi-colour products are already handled. A product that sells in several glazes from one listing appears under every colour it comes in automatically, each with its own photo — no tagging needed. Persian Metal Handi is the live example: it shows under both Copper and Silver.
