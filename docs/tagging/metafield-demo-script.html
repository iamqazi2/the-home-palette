Colour Metafield
Demo Script

Showing the client that Shopify's own Color field now drives Shop by Colour — the products file themselves into the palette, with no tagging at all.

This demo needs the new code on a theme first. The change is written and pushed to git, but it is not on your store. Section 1 puts it on an unpublished preview theme — the live site is never touched.

Version 1.0 · 8 September 2026 · Store: thehomepalette.com.pk
Branch: shop-by-colour-metafield · Subject: Arabic Mandi Platter → Copper

What the client is going to see

Shopify already stores a Color on most products, under Category metafields on the product page. Until now Shop by Colour ignored it and guessed from the product's name. It no longer guesses.

1. Prep — put the code on a preview theme

Ten minutes, off camera. Nothing here changes the live storefront.

  1. Pull the branch: git checkout shop-by-colour-metafield
  2. Push it to a brand-new unpublished theme:
shopify theme push --unpublished --theme "Colour metafield preview"
  1. The CLI prints a preview URL. That is your storefront tab for this demo.
  2. Open it, go to Shop by Colour, click Copper. You should count 6, including Mughal Serving Platter and Royal Mandi Platter.
  3. Open the live site in another tab and click Copper there: 4. Keep both tabs — the contrast is shot 1.
Pull before you push. Theme settings reach the repo through Shopify's automatic "Update from Shopify" commits. Those were merged on 8 September, so main is current — but if more have landed since your last pull, pushing from a stale checkout would revert theme-editor changes. Run git pull first; the push above then goes to a new unpublished theme and cannot affect the live site either way.
If the two platters do not appear on the preview, stop and tell me before the client session. Both are verified to carry Copper in their Color metafield today, so if they are missing, the metafield is not being read and the rest of the demo will not work either.

Pre-flight checklist

  • Preview theme pushed, preview URL saved
  • Copper reads 6 on the preview and 4 on the live site
  • Arabic Mandi Platter's Color field checked: it says Silver, not Copper
  • Two tabs only — admin and preview — everything else closed
  • Full run-through done once, then the Copper entry removed again

2. The demo — about 6 minutes

Shot 1 — the site was guessing

~90 seconds · both storefront tabs
  1. On the live tab, open Shop by Colour → Copper. Four products.
  2. Point out what they have in common: every one has the word copper in its name, or is sold in a Copper variant.
  3. Switch to the preview tab, same swatch. Six products.
  4. Point at the two newcomers: Mughal Serving Platter and Royal Mandi Platter.

"Neither of these has 'copper' anywhere in its name — so the old site had no way of knowing, and left them out of the palette. Nobody tagged them just now. Their Color field in Shopify already said Copper; the site simply started reading it."

Both platters are currently out of stock, so they carry a Sold out badge. Get in front of it — "those two are between deliveries" — rather than letting the client spot it and ask.

Shot 2 — where the colour lives

~60 seconds · admin tab
  1. Open Products → Arabic Mandi Platter.
  2. Scroll to Category metafields. The category reads Serving Platters.
  3. Rest on the Color row. It currently says Silver.

"This is the field, and it's Shopify's own — not something we invented. It's already on every product, under the product category. Right now this platter says Silver."

Shot 3 — add a colour, live

~90 seconds · admin, then preview
  1. Click the Color field. Type Copper and pick the existing Copper entry from the list.
  2. Leave Silver in place — two colours on one product is the point.
  3. Click Save and wait for the confirmation.
  4. Switch to the preview tab, hard-refresh (Cmd+Shift+R), click Copper.
  5. Seven products. Rest the cursor on the Arabic Mandi Platter card.
  6. Click Silver. It is there too — same product, both palettes, one entry each.

"One field, two colours, and it now appears under both — no tags, no duplicate listings, no developer. And because this is Shopify's own colour field, it's the same field that feeds search, filters and the sales channels."

Shot 4 — the products you never have to touch

~60 seconds · optional

Only if the client asks about products sold in many colours.

  1. Still on the preview, click Copper, then Silver. Persian Metal Handi is in both.
  2. Open it in the admin: it has a Color variant option with Copper and Silver.

"This one sells in two finishes from a single listing, so it already appears under both — each showing its own photo. Products like this need nothing at all: the variants do the work."

3. Questions to expect

QuestionAnswer
"So do we still need colour tags?"No. The tag still works and still wins, but the metafield does the same job. Use whichever is already filled in; do not do both.
"What if the colour name isn't in the list?"You can add your own entry — several already exist in this store: Burnt Maple, Lunar Ash, Reactive Cloud Grey, Santorini Blue, Riviera Blue, Blush Peach, Honey Mustard, Earthen Rose, Mist Green.
"What if Shopify's name differs from our palette name?"Nothing gets renamed. Add Shopify's wording to that swatch's Aliases field in the theme editor and both names match from then on.
"How fast is it?"Immediately — it is read live off the product on every page load.
"Can a product be in several colours?"Yes, as many as its Color field lists. You just saw one in two.
"Will this put things in the wrong colour?"Be straight — see the box below. It can, where the Color field lists accents as well as the main colour.
Do not oversell this. The Color field often lists accent colours and patterns, not only the main colour, so a few products land in more swatches than you would choose by hand. Two in the first fifty checked: Ivory White Platter shows under Black, and the 3D Teal Matte Spiral Plate shows under Sage Green. If the client raises it, the honest answer is that the theme can be set to read only the first colour listed — the primary one — which removes both without losing the two platters from shot 1. Offer it as a decision for them, not a defect.

4. After the demo

  • Remove Copper from Arabic Mandi Platter's Color field — or keep it, since it is a correct value for that product
  • Decide with the client: all listed colours, or first colour only
  • Delete the preview theme, or keep it until the change is approved for the live site
  • Merge shop-by-colour-metafield once approved, then publish
