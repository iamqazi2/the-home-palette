1. How tagging works here

Every tag goes in the same place: the Tags box inside the Product organization card on the right-hand side of the product page in Shopify admin. There is nothing else to configure per product.

What the tag does depends on the section:

SectionWhat the tag actually does
Shop by OccasionThe homepage card links to a Shopify automated collection. That collection has one rule: Product tag is equal to …. Tag the product and it joins the collection within seconds.
Shop by StyleIdentical mechanism — an automated collection with a single tag rule.
Shop by ColourNo collection involved. The theme reads the tag directly off the product and files it under the matching swatch.
Golden rules
  • Tags are lowercase with hyphens. Type them exactly as printed in this manual.
  • Shopify autocompletes existing tags — always pick the suggestion rather than retyping, so you never create occasion-eid and Occasion-Eid as two separate tags.
  • A product may carry as many of these tags as genuinely apply. A gold-rimmed platter can be occasion-eid, occasion-wedding-gifts, style-contemporary and gold all at once.
  • Press Enter after each tag, then Save.

2. How to add a tag — step by step

  1. Shopify admin → Products → open the product.
  2. Scroll the right-hand column to the Product organization card.
  3. Click into the Tags field.
  4. Start typing the tag. A dropdown of existing tags appears — click the matching suggestion. Only type it in full if it is a brand-new tag from this manual.
  5. Press Enter. The tag appears as a grey chip below the field.
  6. Repeat for every tag that applies (occasion, style, colour, plus online).
  7. Click Save (top right).
  8. Open the storefront homepage and hard-refresh. The product should now appear under its swatch / card.

Tagging many products at once

  1. Products list → tick the checkboxes of the products.
  2. Click Add tags in the bulk action bar at the top.
  3. Type or select the tag → Apply changes.
Careful: bulk Add tags adds to every selected product. Only bulk-tag products that all share the same occasion, style or colour.

Which style is which?

  • Minimalist — plain, undecorated, single flat colour; clean silhouettes.
  • Earthy — natural materials and textures: jute, rattan, wood, rope, unglazed clay.
  • Reactive — reactive-glaze stoneware where the colour pools and varies piece to piece.
  • Contemporary — patterned or decorated modern tableware; full dinner/breakfast sets.
  • Hotel Collection — hospitality-grade serveware, crisp white/ivory, stackable.

5. Shop by Colour — exact tags

Twenty-one swatches. These do not use collections — the theme reads the tag straight off the product, so the tag works the moment you save.

Important — when the colour tag is ignored

If the product has a variant option literally named Color, Colour, Shade or Glaze, the theme uses that option and ignores colour tags completely. That is deliberate: a handi sold in nine glazes must appear under nine swatches, each showing its own variant photo.

  • Product sold in several colours from one listing → do not add colour tags. Instead make sure the option is named Color and each option value is spelled exactly as the swatch name in the table below.
  • Product that comes in one colour only → add the colour tag from the table.

Two things that catch people out

  • Aqua vs Aqua-grey. If you tag a product aqua-grey it shows only under Aqua-grey. Without a tag, the theme falls back to the product title — and a title containing "Aqua-grey" is deliberately kept out of plain Aqua. Tagging removes all ambiguity, so tag anything in these two shades.
  • The product must be in at least one collection. Shop by Colour walks the store's collections. A product that belongs to no collection at all will never appear under any swatch, however it is tagged.

6. The online tag — required on everything

The main Shop collection (90 products today) is automated with three rules, all of which must be true:

RuleMeaning
Price is greater than 1The product has a real price
Inventory is greater than 1At least 2 in stock
Product tag is equal to onlineYou must add this tag by hand
Every new product needs the online tag, or it will not appear in the Shop collection no matter how well it is tagged otherwise. Make this the first tag you add.

8. Troubleshooting

SymptomFix
Product does not appear under its colour swatchCheck it is in at least one collection; check it has no Color/Colour/Shade/Glaze variant option (if it does, fix the option values instead of tagging); check the tag spelling against section 5.
Product does not appear on an Occasion or Style pageConfirm the collection exists and is automated on that exact tag (section 9). Then re-check the tag spelling — a trailing space or a capital letter creates a separate tag.
Product missing from the Shop pageMissing online tag, price of 0, or stock of 1 or less.
Two versions of the same tag in the dropdownBulk-select the products on the wrong variant, remove it, add the correct one. Then always pick from autocomplete.
A colour swatch says "Nothing in this shade just yet"No product currently matches. Tag some products, or hide that swatch in the theme editor.
Only 12 products show per colourBy design — the swatch grid is capped at 12. Change it in the theme editor under Shop by Colour → Products to show.

9. One-time setup — collections still to be created

This is a store-admin task, done once. Until it is done, only Tea Time, Earthy and Reactive respond to tags.

Create each missing collection

  1. Shopify admin → Products → Collections → Create collection.
  2. Title: the card name (e.g. Wedding Gifts).
  3. Under Collection type choose Automated.
  4. Set Products must match: all conditions.
  5. Condition: Product tag — is equal to — the tag from the table below.
  6. Save. Note the handle Shopify generates.

Point the homepage cards at them

  1. Online Store → Themes → Customize on the live theme.
  2. Open the THP Shop by Occasion section, click a card block.
  3. Set Collection to the new collection. Clear the "Custom link" field — a custom link overrides the collection, and five of the six cards have one set today.
  4. Repeat for every card, then for each tile in THP Shop by Style (those use the Link field, currently empty — leave it empty and just set the collection).
  5. Save, then check the homepage.
The product counts on the Occasion cards are live. A newly created collection reads "0 varieties" until products are tagged, so tag before you switch the cards over, or switch and tag the same day.

Backfilling the existing catalogue

The three tag-driven collections cover 37, 12 and 8 products. Everything else is untagged for occasion and style, and no product carries a colour tag yet. Suggested order of work:

  1. Bulk-add online to every product that should be sellable.
  2. Work collection by collection — open Plates, tag them all occasion-everyday-dining; open Serveware, tag occasion-hosting-guests; and so on.
  3. Then styles, using the definitions in section 4.
  4. Colours last, and only for products that do not have a colour variant option.
